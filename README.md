## 🚀 Featured Projects

### 1. ⚽ [Football Player Valuation & Scouting Tool](https://github.com/caosfourn/player-undervaluation-scouting-tool)
*An end-to-end player valuation and talent recruitment engine powered by machine learning and interactive Power BI diagnostics.*

<div align="center">

| Dataset & Scope | Architecture & Pipeline | Model Performance | Strategic Impact |
| :---: | :---: | :---: | :---: |
| **81,998 records**<br>(Transfermarkt) | SQL ETL • Point-in-time<br>Rolling 365-day features | **R² = 0.674**<br>(24,264 Out-of-Time test) | **62.2% watchlist sub-€1M**<br>Optimized recruitment budget |

</div>

- **Pipeline & Modeling**: Built an SQL-based ETL process and engineered point-in-time, rolling 365-day performance metrics to prevent data leakage. Trained a CatBoost fair-value model using a strict chronological split (Train: 2012–2020, Validation: 2021–2022, Test: 2023–2026), reaching an $R^2 = 0.674$ on 24,264 out-of-time test valuations.
- **Visualization & Diagnostics**: Developed an interactive Power BI dashboard featuring market overviews, player search filters, automated watchlist rankings, model error diagnostics, and player-level drill-through analysis.
- **Actionable Takeaways**: Identified that sub-€1M players represented 62.2% of the strong-sample watchlist, recommending prioritized scouting in lower-valuation segments prior to tactical/contract reviews.
- 🔗 **Repository**: [`caosfourn/player-undervaluation-scouting-tool`](https://github.com/caosfourn/player-undervaluation-scouting-tool)

### 2. 💳 [Loan Portfolio Risk & Exposure Analytics](https://github.com/caosfourn/Loan-Portfolio-Risk-Exposure-Analytics)
*An institutional credit risk framework analyzing consumer loan delinquency, portfolio health, and exposure concentration.*

<div align="center">

| Portfolio Scope | Data Governance | Statistical Validation | Critical Risk Finding |
| :---: | :---: | :---: | :---: |
| **38,576 loans**<br>**$435.8M exposure** | Python & SQL validation<br>Cross-platform KPI audit | **95% Wilson Score**<br>Confidence Intervals | **60-Month Debt Consolidation**<br>26.1% default vs. 14.2% baseline |

</div>

- **Data Processing & Governance**: Architected a reproducible Python and SQL pipeline enforcing checks for schema, duplicate IDs, missing values, outliers, category normalization, and date consistency. Reconciled governed KPIs for matured default rate, exposure, and collections across Python, T-SQL, and DAX.
- **Risk Analysis & Segmentation**: Dissected risk variance across credit grades, state demographics, debt-to-income (DTI) ratios, home ownership, and loan terms, applying 95% Wilson score confidence intervals.
- **Business Intelligence & Insights**: Designed a 3-page interactive Power BI dashboard with dynamic drill-down capabilities; isolated 60-month debt-consolidation loans as the primary exposure hazard ($92.8M exposure and a 26.1% matured default rate vs. the 14.2% portfolio benchmark).
- 🔗 **Repository**: [`caosfourn/Loan-Portfolio-Risk-Exposure-Analytics`](https://github.com/caosfourn/Loan-Portfolio-Risk-Exposure-Analytics)
