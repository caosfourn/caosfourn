## 🚀 Featured Projects

### 1. 🛍️ Vietnam Fashion E-commerce: Customer Retention & Return Risk Analytics

*Investigating order-value trends, repeat purchasing, and product-return risk in simulated Vietnamese fashion e-commerce data.*

| Dataset | Data Quality | Key Finding | Business Direction |
| :---: | :---: | :---: | :---: |
| **646,945 orders**<br>**714,669 item lines** | **102** data, KPI, and SQL-to-Python checks | **34.97%** of return events attributed to wrong size | Targeted fit-information audit and controlled size-guide test |

- **Business Objective:** Analyzed simulated fashion e-commerce data (2012–2022) to understand changes in order value, repeat purchasing, and return risk.
- **Data Processing:** Built a reproducible **Python/Pandas + SQLite** pipeline, preserved order-item granularity, validated joins and financial definitions, and completed **102 validation checks**.
- **Analysis & Insights:** Decomposed a **44.58% decline** in discount-adjusted order value (2016–2022): order volume decreased **56.22%**, while value per order increased **26.61%**. Built mature **90-day repeat-purchase cohorts** and unit-level return KPIs.
- **Recommendations:** Found wrong size accounted for **34.97% of return events** and **34.69% of returned units**. Proposed a targeted **GenZ XL/M fit-information audit** and controlled size-guide experiment, monitoring the **60-day wrong-size return rate** with conversion and order-value guardrails.

### 2. 📦 Olist E-Commerce Operations & Customer Experience Analytics

*Analyzing delivery reliability, customer satisfaction, logistics costs, and repeat purchasing across Brazilian e-commerce orders.*

| Dataset | Dashboard | Customer Experience | Logistics Insight |
| :---: | :---: | :---: | :---: |
| **99,092 orders**<br>2017–2018 | **4 Power BI pages** | Low-review rate: **25.09% late** vs. **9.23% on-time** | Freight cost: **R$11.89 → R$30.11** beyond 2,000 km |

- **Business Objective:** Studied delivery performance, customer dissatisfaction, regional logistics gaps, repeat purchasing, payment delays, and freight-heavy product categories.
- **Data Processing:** Developed a **SQL Server** workflow with staging, cleaning, dimensional modeling, fact tables, analytical marts, and data-quality checks; used **Python** for reproducible analysis.
- **Analysis & Dashboard:** Built a **4-page Power BI dashboard** for delivery SLAs, delivery stages, priority states/routes, customer reviews, and **90-day retention**. Observed low-review rates of **25.09%** for late orders versus **9.23%** for on-time orders.
- **Recommendations:** Identified **SP/RJ/MG as 66.61% of orders** and higher freight costs for long-distance deliveries. Proposed targeted late-order communications, regional fulfillment experiments, boleto payment-status messaging, and freight optimization.

### 3. 💳 [Loan Portfolio Risk & Exposure Analytics](https://github.com/caosfourn/Loan-Portfolio-Risk-Exposure-Analytics)

*Evaluating consumer-loan portfolio health, delinquency outcomes, and exposure concentration with governed KPIs and Power BI.*

| Portfolio | Risk Validation | Dashboard | Priority Segment |
| :---: | :---: | :---: | :---: |
| **38,576 loans**<br>**$435.8M funded exposure** | **95% Wilson confidence intervals** | **3 Power BI pages** | **26.1%** matured default vs. **14.2%** portfolio benchmark |

- **Business Objective:** Analyzed **2021 consumer-loan applications** to assess portfolio health, delinquency, and risk concentration.
- **Data Processing:** Built a reproducible **Python + SQL** workflow with checks for schema, duplicate IDs, missing values, outliers, categories, and dates; defined consistent exposure, collections, and matured-default KPIs.
- **Risk Analysis:** Segmented risk by credit grade, state, loan purpose, term, debt-to-income ratio, and home ownership. Applied **95% Wilson confidence intervals** and reconciled metrics across **Python, T-SQL, and DAX**.
- **Dashboard & Insights:** Created a **3-page interactive Power BI dashboard**. Flagged **60-month debt-consolidation loans** for review, with **$92.8M exposure** and a **26.1% matured default rate**, compared with **14.2%** for the overall portfolio.
